## Design Specificity Verdict

LLM assessment: The component content model is genuinely domain-grounded — TableParameter, ToggleAudience, Card's 8px petrol top border as a "caption bar" tied to the "Journal Figure" north star. But the showcase shell itself undermines that north star: buttons/+page.svelte and data/+page.svelte use raw <h3> instead of the shipped H3 component, and the /components index uses hand-rolled .group-card divs instead of the system's own Card.

Deterministic scan: 92 findings from impeccable detect over src/lib + src/routes: 65x design-system-font-size, 18x design-system-color, 7x design-system-radius, 2x side-tab (likely false positive — InfoBox.svelte's left border is intentional per its own doc comment, but undocumented at the system level in DESIGN.md).

Visual overlays: Not available — no browser/screenshot tool exposed in this session (confirmed by both assessments via ToolSearch; dev server itself confirmed live via curl). Fell back to source reading and grep-based mechanical evidence.

## Overall Impression

The component vocabulary is honest and purpose-built for this lab. What's missing is the system enforcing itself on itself: zero keyboard-focus styling anywhere, 92 tokens quietly drifted from what DESIGN.md documents, two components reference CSS variables that don't exist, and five public export names don't match their own filenames.

## What's Working

- TableParameter.svelte — monospace, tabular-nums value column purpose-built for kinetic-parameter comparison.
- ToggleAudience.svelte — audience-segmented content switching, a real teaching-site need.
- The ShowcaseSection pattern (live preview + copy-pasteable snippet, backed by @component doc comments) — Help & Documentation scored 4/4.

## Priority Issues

[P0] Zero keyboard focus indicators anywhere in the library
- Why it matters: Confirmed independently by both assessments — zero :focus/:focus-visible rules across ~110 components; 27 files with interactive elements and no focus styling anywhere in the same file or globally. PRODUCT.md commits to a WCAG AA baseline including keyboard navigation.
- Fix: One rule in tokens.css — :focus-visible { outline: 2px solid var(--color-primary); outline-offset: 2px; } — propagates to every consumer on next sync.
- Suggested command: /impeccable audit

[P1] 92 undocumented token deviations (65 font-size, 18 color, 7 radius)
- Why it matters: Quantitative backing for Assessment A's independent 1/4 "Consistency and Standards" score. Examples: Accordion2.svelte:134 at 1.33rem, CardPerson.svelte:95 at 14px, DynBoxGrid.svelte raw #d0d0d0/#5a5a5a.
- Fix: Triage the 92 findings in one pass — snap true drift onto the existing scale; promote recurring intentional values (e.g. CardFeature.svelte's 20px radius) to real token steps.
- Suggested command: /impeccable polish

[P1] Two components reference CSS custom properties that don't exist
- Why it matters: CardPerson.svelte:127 sets color: var(--white) — undefined anywhere in tokens.css; the name bar for real lab people's names risks illegible text. Popover.svelte:75 sets box-shadow: var(--shadow) — only --shadow-sm/-md/-primary exist, so the system's one floating surface silently ships flat, contradicting DESIGN.md's own Flat-Unless-Selectable Rule.
- Fix: CardPerson.svelte:127 -> var(--color-text-inverse); Popover.svelte:75 -> var(--shadow-md).
- Suggested command: /impeccable harden

[P1] Public export names invert their own filenames
- Why it matters: index.ts exports TableParameter.svelte as ParameterTable, ToggleAudience.svelte as AudienceToggle, SliderActivation.svelte as ActivationSliders, RowImgScrolling.svelte as LogoBar, Box.svelte as Div. Breaks grep-driven discovery for the exact persona PRODUCT.md ships for.
- Fix: Pick one direction — filename or export name — and align all five.
- Suggested command: /impeccable clarify

[P3] /components index has 2 of 11 category links hardcoded without base
- Why it matters: interactive and media use a bare href while the other 9 use ${base}-prefixed hrefs. Will 404 on any non-root deploy path.
- Fix: Template all 11 identically.
- Suggested command: /impeccable harden
